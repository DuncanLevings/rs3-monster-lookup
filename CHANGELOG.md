# Changelog

## 0.0.1 - Unreleased

- Add a **View drops** option to the right-click menu of attackable monsters.
- Show drop tables from the RuneScape Wiki with quantities, rarities, GE prices and notes.
- Add item search, collapsible categories and an optional percentage rarity display.
- Add a **Monster info** tab with combat stats, weaknesses, immunities and Slayer details,
  including a selector for monster variants.
- Save lookups between sessions, with a configurable refresh interval and a manual Refresh.
- Remember the window's position and size.
- Add a mode picker for pages with several drop modes, such as normal and hard mode.
- Add a **View drops** colour setting; the option now matches the other menu entries by default.
- Show a placeholder icon for drops that aren't inventory items.
- Show the full quantity on hover when it is cut off.
- Fix boss mode descriptions repeating above every drop category; average value lines from
  the Wiki now show once per mode.
